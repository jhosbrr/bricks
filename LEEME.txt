BRICKS 2.0 — Brick by brick

Subí estos cinco archivos al repositorio de GitHub Pages:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

Antes de futuras actualizaciones, abrí Bricks > Más > Exportar respaldo.
Los datos se guardan localmente en Safari y no se suben a GitHub.


ACTUALIZACIÓN 2.1
- Ahora podés tocar BAC, BCR o Efectivo para editar el saldo actual.
- Editar una cuenta ya no crea una cuenta duplicada.
- El dashboard principal usa un verde salvia claro.
- Los ingresos programados siguen siendo estimaciones; el depósito real se registra con el botón + como ingreso.


ACTUALIZACIÓN 2.2
- Ahora se pueden eliminar movimientos desde la pantalla Movimientos.
- Ahora se pueden eliminar pagos pendientes o pagados.
- Se solicita confirmación antes de borrar.
- Al borrar un movimiento, el saldo se recalcula automáticamente.
- Al borrar un pago ya pagado, su movimiento permanece y puede eliminarse aparte.
- “Construcciones” ahora se llama “Metas”.
